# Saranya.M Portfolio — Final

A neat, responsive portfolio built with HTML, CSS and JavaScript.

## Structure

```text
saranya-portfolio-final/
│
├── index.html
│
├── assets/
│   ├── css/
│   │   ├── base.css
│   │   ├── layout.css
│   │   ├── components.css
│   │   ├── responsive.css
│   │   └── final-tuning.css
│   │
│   ├── js/
│   │   └── interactions.js
│   │
│   ├── images/
│   │   └── profile.jpg
│   │
│   └── documents/
│       └── resume.pdf
│
└── README.md
```

## CSS files

- `base.css` — global design system, colours, typography and reset.
- `layout.css` — navigation, grids, sections and page structure.
- `components.css` — cards, tags, experience, projects, leadership, contact and modal.
- `responsive.css` — tablet and mobile behaviour.
- `final-tuning.css` — final visual adjustments requested for this portfolio.

## JavaScript

Only one JavaScript file is needed. `interactions.js` controls the clickable skill and project technology detail modal.

## Replace before publishing

1. `assets/images/profile.jpg` with the actual profile photograph.
2. `assets/documents/resume.pdf` with the actual resume.
3. Replace the LinkedIn and GitHub placeholder URLs in `index.html`.
4. Add real GitHub/demo links to individual projects when available.

## Run in VS Code

Open the folder in VS Code and use Live Server on `index.html`.
